## 주천학 선언

주천학(周天學)은 공간(주)과 시간(후)의 순환 원리를 연구하는 학문이다.

주와 후는 끊임없이 순환하며 서로 만나고, 그 만남을 통해 모든 현상은 생성·변화·순환한다.

갑자, 괘, 효, 절기, 24주, 72룡, 72후, 오행, 풍수, 사주 등은 모두 이러한 주천의 질서를 표현하는 매체이다.

주천학은 각각의 매체를 따로 연구하는 것이 아니라, 하나의 시공간 좌표계 위에서 통합적으로 이해하는 것을 목적으로 한다.
